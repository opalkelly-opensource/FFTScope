FrontPanel HDL Sources
======================

Locate the Bandwidth Mode "BWMode3" folder for your product in the
FrontPanel SDK:

   <FrontPanel SDK>/FrontPanelHDL/<product_name>/BWMode3

Copy it into this directory. The result should look like:

   FrontPanel/BWMode3/
       okHost.vp
       okHost.xdc

See the parent README.txt for full build instructions.
